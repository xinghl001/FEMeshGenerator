## 系统安装

### 1. 系统要求

- **操作系统**：Windows 10 或 Windows 11 (64位)
- **内存**：至少 4GB RAM（推荐 8GB 以上）
- **显卡**：支持 OpenGL 的显卡
- **磁盘空间**：至少 100MB 可用空间

### 2. 安装步骤

#### 方式一：使用预编译版本

1. 从 [Release 页面](https://github.com/xinghl001/FEMeshGenerator/releases) 下载最新版本
2. 解压到任意目录
3. 双击 `FEMeshGenerator.exe` 运行

#### 方式二：从源代码编译

1. 安装 Visual Studio 2022
   - 勾选"使用 C++ 的桌面开发"工作负载
   - 确保包含 MFC 组件

2. 克隆代码仓库
```bash
git clone https://github.com/xinghl001/FEMeshGenerator.git
```

3. 打开 Visual Studio
   - 打开 `FEMeshGenerator.sln`
   - 选择 x64 平台
   - 选择 Release 配置
   - 按 F7 编译

4. 运行程序
   - 编译完成后，可在 `x64\Release` 目录找到 `FEMeshGenerator.exe`

### 功能区域说明

#### 1. OpenGL 3D 视图区域（左侧）
- **功能**：实时显示生成的三维网格模型
- **交互**：
  - 按住鼠标左键拖动：旋转视图
  - 鼠标滚轮：缩放视图
  - 坐标轴颜色：X轴-红色、Y轴-绿色、Z轴-蓝色

#### 2. 参数输入区域（右侧）
- **几何参数组**：定义T型结构的基本尺寸
- **焊缝参数组**：控制焊缝形状和类型
- **网格密度组**：设置不同区域的单元大小
- **文件设置组**：指定输入输出文件路径

#### 3. 操作按钮
- **生成网格**：根据当前参数生成网格
- **导出INP**：保存网格为INP文件
- **加载模板**：加载焊缝截面模板
- **重置参数**：恢复默认值

#### 4. 状态栏（底部）
- 显示当前网格的节点数和单元数

## 操作步骤

### 基本操作流程

#### 第一步：加载模板文件

1. 点击"浏览..."按钮
2. 选择 `data\yao.inp` 文件
3. 点击"加载模板"按钮
4. 等待提示"模板文件加载成功！"

#### 第二步：设置参数

**几何参数设置建议**：
```
L1 = 200mm  （主板长度，范围：100-500mm）
L2 = 150mm  （副板长度，范围：50-300mm）
W1 = 100mm  （主板宽度，范围：50-200mm）
W2 = 80mm   （副板宽度，范围：40-150mm）
t1 = 10mm   （主板厚度，范围：5-50mm）
t2 = 8mm    （副板厚度，范围：5-40mm）
t3 = 5mm    （过渡厚度，范围：2-20mm）
R = 20mm    （缺口半径，范围：10-50mm）
d = 30mm    （肋骨距离，范围：10-100mm）
```

**焊缝参数设置建议**：
```
HW = 6.0mm  （焊缝高度，范围：3-15mm）
LW = 6.0mm  （焊缝长度，范围：3-20mm）
k = 2.0     （幂系数，范围：1.0-5.0）
```

**网格密度设置建议**：
- 密度值越小，网格越细，计算精度越高，但计算量也越大
- 焊缝区：1.0-3.0mm（关键区域，建议密度小）
- 过渡区：2.0-5.0mm（中等密度）
- 平板区：3.0-10.0mm（可用较大密度）

#### 第三步：生成网格

1. 检查所有参数设置是否合理
2. 点击"生成网格"按钮
3. 在左侧3D视图中查看生成结果
4. 使用鼠标旋转和缩放查看细节
5. 查看状态栏确认节点和单元数量

#### 第四步：导出文件

1. 在"输出文件"框中输入文件名（如 `my_mesh.inp`）
2. 点击"导出INP"按钮
3. 等待提示"INP文件已导出到: xxx"
4. 在程序目录下找到生成的INP文件

### 高级操作

#### 调整幂曲线系数

幂曲线系数 `k` 控制焊缝形状：

- **k = 1.0**：线性变化，焊缝呈直线形
- **k = 2.0**：抛物线形（默认，最常用）
- **k = 3.0**：更陡峭的曲线
- **k > 3.0**：非常陡峭，接近直角

建议根据实际焊缝形状选择合适的 k 值。

#### 优化网格质量

1. **避免单元扭曲**
   - 保持相邻区域密度比不超过 2:1
   - 例如：焊缝区2.0mm，过渡区不超过4.0mm

2. **控制总网格数量**
   - 初步建模：使用较大密度值快速生成
   - 精细分析：逐步减小密度值细化网格
   - 建议总单元数控制在 10万以内

3. **检查网格连续性**
   - 旋转视图检查是否有间隙
   - 确认所有区域都生成了网格

## 参数说明

### 几何参数详解

#### L1 - 主板长度
- **定义**：T型结构底板的长度
- **单位**：mm
- **建议范围**：100-500mm
- **影响**：决定整体结构长度

#### L2 - 副板长度
- **定义**：T型结构竖板的长度
- **单位**：mm
- **建议范围**：50-300mm
- **影响**：决定T型高度

#### W1 - 主板宽度
- **定义**：底板的宽度
- **单位**：mm
- **建议范围**：50-200mm
- **影响**：影响焊缝分布范围

#### W2 - 副板宽度
- **定义**：竖板的宽度
- **单位**：mm
- **建议范围**：40-150mm
- **注意**：通常 W2 ≤ W1

#### t1, t2 - 板厚
- **定义**：主板和副板的厚度
- **单位**：mm
- **建议范围**：5-50mm
- **影响**：影响结构刚度和网格层数

#### t3 - 过渡厚度
- **定义**：焊缝到平板的过渡区域厚度
- **单位**：mm
- **建议范围**：2-20mm
- **作用**：平滑连接焊缝和平板

#### R - 缺口半径
- **定义**：焊缝根部的圆角半径
- **单位**：mm
- **建议范围**：10-50mm
- **作用**：减少应力集中

#### d - 肋骨距离
- **定义**：加强肋骨的间距
- **单位**：mm
- **建议范围**：10-100mm
- **作用**：结构加强

### 焊缝参数详解

#### HW - 焊缝高度
- **定义**：焊缝从根部到顶部的高度
- **单位**：mm
- **建议范围**：3-15mm
- **影响**：焊缝截面大小

#### LW - 焊缝长度
- **定义**：焊缝沿路径方向的长度
- **单位**：mm
- **建议范围**：3-20mm
- **影响**：焊缝区域范围

#### k - 幂曲线系数
- **定义**：控制焊缝形状的幂次
- **范围**：1.0-5.0
- **建议值**：2.0（抛物线形）
- **公式**：`y = HW * (1 - (x/LW)^k)`

#### 双边焊缝选项
- **☑ 选中**：生成T型两侧的焊缝
- **☐ 未选**：仅生成单侧焊缝

### 网格密度详解

#### 焊缝区密度
- **定义**：焊缝区域的单元特征尺寸
- **建议**：1.0-3.0mm
- **原则**：应力梯度大的区域使用小密度

#### 过渡区密度
- **定义**：焊缝到平板过渡区的单元尺寸
- **建议**：2.0-5.0mm
- **原则**：介于焊缝和平板之间

#### 平板区密度
- **定义**：远离焊缝的平板区域单元尺寸
- **建议**：3.0-10.0mm
- **原则**：应力变化缓慢的区域可用大密度

### 与 Abaqus 配合使用

#### 导入到 Abaqus/CAE

1. 启动 Abaqus/CAE
2. File → Import → Model
3. 选择生成的 INP 文件
4. 查看导入的网格模型

#### 在 HyperMesh 中使用

1. 启动 HyperMesh
2. File → Import → Solver Deck
3. 选择 Abaqus 求解器
4. 导入 INP 文件
5. 进行后续编辑和分析设置

### 网格质量检查

在 Abaqus 中检查网格质量：

```
Mesh → Verify
```

重点检查指标：
- Aspect Ratio（长宽比）< 5
- Warpage（翘曲）< 10°
- Jacobian > 0.6
- Skew（偏斜）< 45°

## 故障排除

### 常见问题

#### 1. 程序无法启动

**症状**：双击 exe 文件无响应或报错

**解决方案**：
- 确认是 64 位 Windows 系统
- 安装 Visual C++ 2022 Redistributable
- 检查是否缺少 DLL 文件
- 以管理员身份运行

#### 2. OpenGL 视图黑屏

**症状**：左侧 3D 视图区域全黑

**解决方案**：
- 更新显卡驱动
- 检查 OpenGL 支持（需要 OpenGL 2.0+）
- 在集成显卡和独立显卡之间切换
- 尝试在兼容模式下运行

#### 3. 加载模板失败

**症状**：点击"加载模板"后提示失败

**解决方案**：
- 确认文件路径正确
- 检查 `yao.inp` 文件是否存在
- 验证文件格式是否为 ASCII 编码
- 检查文件是否被其他程序占用

#### 4. 生成网格失败

**症状**：点击"生成网格"后提示失败

**解决方案**：
- 先确认已加载模板文件
- 检查参数是否合理（不能为负数或零）
- 减小网格密度（增大密度值）
- 检查内存是否充足

#### 5. 导出 INP 失败

**症状**：无法保存 INP 文件

**解决方案**：
- 检查输出路径是否有写入权限
- 确保文件名不包含非法字符
- 检查磁盘空间是否充足
- 关闭可能占用该文件的程序

#### 6. 网格显示不正常

**症状**：网格出现间隙、重叠或扭曲

**解决方案**：
- 调整网格密度参数
- 检查几何参数是否合理
- 重新生成网格
- 导出后在 Abaqus 中检查

### 性能优化

#### 大规模网格

生成大规模网格（>5万单元）时：

1. 先用粗网格测试参数
2. 分阶段细化网格
3. 关闭不必要的后台程序
4. 使用 Release 编译版本

#### 渲染优化

如果视图卡顿：

1. 增大网格密度值（减少网格数）
2. 关闭其他占用 GPU 的程序
3. 降低系统显示设置
4. 使用性能更好的显卡

### 文件格式

#### INP 文件格式说明

生成的 INP 文件符合 Abaqus 标准格式，包含：

- `*HEADING`：文件头信息
- `*NODE`：节点坐标列表
- `*ELEMENT`：单元连接关系
- `*ELSET`：单元集定义
- `*MATERIAL`：材料属性
- `*END`：文件结束标记

### 单位系统

程序内部使用一致的单位系统：

- 长度：mm
- 力：N（如需要）
- 应力：MPa（如需要）
- 模量：MPa
