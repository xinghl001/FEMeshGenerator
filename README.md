## 📋 项目简介

FEMeshGenerator 是一个基于 C++ MFC 和 OpenGL 的 T 型焊接结构有限元网格自动生成工具。该程序可以根据用户输入的几何参数和网格密度要求，自动生成符合 Abaqus INP 格式的三维六面体网格模型。

### 主要特性

- ✅ **参数化建模**：通过直观的界面输入几何参数，自动生成网格
- ✅ **幂曲线变形**：实现焊缝区域的幂曲线变形算法 `y = h2 * (1 - (x/h1)^k)`
- ✅ **扫描拉伸算法**：基于 2D 模板截面的扫描拉伸网格生成
- ✅ **3D 实时可视化**：OpenGL 实时显示生成的三维网格模型
- ✅ **交互式操作**：支持鼠标旋转、缩放查看网格
- ✅ **INP 格式导出**：导出标准 Abaqus INP 文件，可直接导入 HyperMesh/Abaqus

### 使用步骤

1. **启动程序**
   - 运行编译好的 FEMeshGenerator.exe

2. **加载模板**
   - 点击"浏览..."按钮选择 `data/yao.inp` 模板文件
   - 点击"加载模板"按钮

3. **设置参数**
   - 在右侧面板输入几何参数
   - 设置焊缝参数和网格密度

4. **生成网格**
   - 点击"生成网格"按钮

5. **导出文件**
   - 输入输出文件名（默认：output_mesh.inp）
   - 点击"导出INP"按钮
   - 生成的 INP 文件可导入 Abaqus/HyperMesh

## 📐 技术原理

### 幂曲线变形算法

焊缝区域的形状通过幂曲线公式控制：

```
y = h2 * (1 - (x/h1)^k)
```

其中：
- `h1`：焊缝长度 (LW)
- `h2`：焊缝高度 (HW)
- `x`：沿路径的位置坐标
- `k`：幂曲线系数（控制曲线形状）

**k 值对形状的影响：**
- `k = 1`：线性变化
- `k = 2`：抛物线形状（默认，符合常见焊缝轮廓）
- `k > 2`：更陡峭的曲线

### 扫描拉伸算法

1. **加载 2D 截面模板**
   - 从 `yao.inp` 读取 2D 四边形单元
   - 提取节点坐标和单元连接关系

2. **定义扫描路径**
   - 根据焊缝长度和网格密度计算路径点数
   - 均匀分布路径点

3. **沿路径复制截面**
   - 在每个路径点处复制模板节点
   - 应用幂曲线变形调整 Y 坐标

4. **生成六面体单元**
   - 连接相邻截面的对应节点
   - 2D 四边形扩展为 3D 六面体（C3D8R）
   - 管理节点和单元 ID

### INP 文件格式

生成的 INP 文件包含以下部分：

```
*HEADING
T-Joint Fillet Weld Structure - Generated by FEMeshGenerator

*NODE
节点ID, X坐标, Y坐标, Z坐标

*ELEMENT, TYPE=C3D8R, ELSET=ALL_ELEMENTS
单元ID, 节点1, 节点2, ..., 节点8

*ELSET, ELSET=WELD
*ELSET, ELSET=TRANSITION
*ELSET, ELSET=PLATE

*MATERIAL, NAME=STEEL
*ELASTIC
210000., 0.3

*END
```

## ❓ 常见问题

### 编译问题

**Q: 提示找不到 MFC 库？**
A: 确保在 Visual Studio Installer 中安装了"使用 C++ 的桌面开发"工作负载，并勾选"MFC"组件。

**Q: 提示 Windows SDK 版本不匹配？**
A: 在项目属性中将"Windows SDK 版本"设置为已安装的版本，或安装项目指定的 SDK 版本。

### OpenGL 问题

**Q: 程序启动后 OpenGL 视图为黑屏？**
A: 检查显卡驱动是否支持 OpenGL，尝试更新显卡驱动程序。

**Q: 网格显示不正确或闪烁？**
A: 检查双缓冲是否启用，确保在 `OnPaint` 中调用 `SwapBuffers`。

### 文件格式问题

**Q: 导出的 INP 文件无法在 Abaqus 中导入？**
A: 
- 检查 INP 文件格式是否正确
- 确认节点和单元 ID 没有重复
- 验证单元节点顺序是否符合 C3D8R 要求

**Q: 模板文件 yao.inp 加载失败？**
A: 
- 确认文件路径正确
- 检查文件编码（建议使用 ASCII）
- 验证文件格式符合 Abaqus INP 规范

### 使用问题

**Q: 生成的网格质量不佳？**
A: 
- 调整网格密度参数
- 修改幂曲线系数 k 值
- 检查几何参数是否合理

**Q: 程序运行缓慢？**
A: 
- 增大网格密度值（减少网格数量）
- 对于大规模网格，考虑优化显示列表
- 在 Release 模式下编译运行
